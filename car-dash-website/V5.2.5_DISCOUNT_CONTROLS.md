# Car Dash Detailing v5.2.5 — Discount Usage Controls

This release adds owner controls for discount-code limits without requiring a Prisma schema migration.

## New discount controls

Owner → Add-Ons & Discounts now supports:

- **Total usage limit** — leave blank for unlimited use.
- **One use per customer** — enforced using the signed-in account when available and customer email as a fallback.
- **Expiration date** — valid through the selected date in the America/Chicago time zone.
- **Usage counter** — shows how many successful booking requests have used each code.
- Automatic **Expired** and **Limit reached** status badges.

## Enforcement

Discount rules are checked twice:

1. When the customer presses **Apply Code**.
2. Again on the server when the booking is submitted.

This prevents a customer from keeping an already-applied code if it expires, reaches its usage limit, or has already been used by that customer before the booking is submitted.

Existing discount codes remain compatible. New fields default to unlimited uses, no per-customer restriction, and no expiration date.

## Usage tracking

The site counts actual booking requests that contain the discount code in their booking record. Existing bookings created with earlier V5.1+ discount codes are included in the usage count.

No database schema migration is required for this release.
