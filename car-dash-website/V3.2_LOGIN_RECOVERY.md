# Car Dash V3.2 — Login Recovery

V3.2 keeps every V3.1 Twilio/quote/booking feature and hardens authentication recovery.

## What changed

- Normal customer/admin login still uses the password hash stored in PostgreSQL.
- Email lookup now has a case-insensitive legacy fallback.
- Owner login can recover from a missing owner database row when the submitted password matches the private `OWNER_PASSWORD` Vercel variable.
- If the owner row exists but its password hash is stale/corrupt, the same private recovery credential can repair the hash and role.
- `/api/health` now verifies the `User` table itself and reports only safe booleans:
  - `userTable`
  - `ownerAccountExists`
  - `ownerRecoveryConfigured`
- No database migration or `prisma db push` is required.
- Twilio credentials and messaging behavior are unchanged.

## Expected health output

```json
{
  "ok": true,
  "database": "connected",
  "databaseSource": "DATABASE_URL",
  "userTable": "ready",
  "authSecretConfigured": true,
  "ownerEmailConfigured": true,
  "ownerAccountExists": true,
  "ownerRecoveryConfigured": true,
  "twilioConfigured": true
}
```

If `ownerAccountExists` is false but `ownerRecoveryConfigured` is true, signing in with the owner email and the private Vercel `OWNER_PASSWORD` will recreate the owner row automatically.
