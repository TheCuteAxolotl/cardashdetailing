# v5.1.8 — Next.js build fix

Fixed the TypeScript build error in `src/app/api/sms/connection/route.ts` where the `error` property was declared before spreading `result`, causing TypeScript to report that `error` was specified more than once.

The response object now spreads `result` first and then explicitly sets `error`, preserving the same API payload while compiling cleanly with respect to that error.
