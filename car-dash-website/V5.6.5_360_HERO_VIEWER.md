# v5.6.5 — 360 Hero Viewer

- Replaced the homepage static hero media with a frame-based 360 viewer.
- Owner Dashboard → Photos & Videos now has `Homepage → 360 Hero Viewer → Rotation Frames`.
- Upload the photos in rotation order. 8 frames is workable; 12–24 is smoother.
- Customers can drag on desktop, swipe on mobile, use the arrow buttons, or use keyboard arrows.
- The viewer loops continuously from the last frame back to the first.
- If no 360 frames have been uploaded, the homepage hero media area stays blank/dark instead of showing a fake placeholder.
- A single uploaded frame displays as a normal static image until additional frames are added.
- The old `hero` placement remains available as the global fallback hero for other public pages.
