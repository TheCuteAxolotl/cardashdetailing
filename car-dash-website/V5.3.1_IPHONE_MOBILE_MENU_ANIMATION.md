# Car Dash Detailing v5.3.1 — iPhone Mobile Menu Animation

## Changed
- The mobile navigation now stays mounted and smoothly slides down/up instead of appearing instantly.
- Added iPhone/Safari-friendly max-height, opacity, and translate transitions.
- Kept momentum scrolling (`-webkit-overflow-scrolling: touch`) for long mobile menus.
- Services and Explore accordions now animate their actual height smoothly when opened or closed.
- Existing reduced-motion accessibility behavior is preserved.

## Scope
This is a UI-only change to the public header navigation. No database, Twilio, booking, staff-role, quote, pricing, or account logic was changed.
