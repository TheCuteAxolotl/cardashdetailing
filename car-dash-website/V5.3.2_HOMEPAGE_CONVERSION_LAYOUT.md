# V5.3.2 — Homepage Conversion Layout

This release applies the latest homepage UX feedback while preserving the existing quote, account, staff, booking, SMS, voice, pricing, and owner systems.

## Homepage changes

- Keeps the main **Get an Exact Quote** CTA in the hero.
- Removes repeated quote CTAs from lower homepage sections.
- Adds a compact floating **Get an Exact Quote** button after the visitor scrolls past the hero. It sits beside the existing **Need help?** launcher.
- Replaces the connected service-card strip with three clearly separated service cards:
  - Car Detailing
  - Paint + Protection
  - Marine Detailing
- Each service card routes to a dedicated service/category page instead of immediately forcing a quote action.
- Adds live Google reviews directly near the bottom of the homepage using the existing Google Reviews integration.
- Removes the large repeated bottom quote CTA so the homepage has one primary hero CTA plus the floating CTA after scroll.
- Keeps the existing recent-work gallery, About/FAQ paths, social links, and owner-editable homepage copy.

## No backend changes

No database migration or new environment variable is required for v5.3.2.
