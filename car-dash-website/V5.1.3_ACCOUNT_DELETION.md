# V5.1.3 — Customer Account Deletion

Added self-service customer account deletion to the Account page.

## What changed

- Added a **Danger Zone** on `/account` for normal customer accounts.
- Customers must enter their current password and type `DELETE` before the destructive button is enabled.
- Added `DELETE /api/auth/delete-account` with authentication and password verification.
- Owner/admin accounts are protected from deletion through the customer endpoint.
- Successful deletion clears the authentication cookie and returns the visitor to the home page.
- Customer-owned relational data is removed according to the existing Prisma cascade rules.
- Updated the Privacy Policy to disclose the self-service deletion option.

## Version

Package version bumped from 5.1.2 to 5.1.3.
