# v5.1.2 — Services dropdown direct anchor fix

- The desktop Services dropdown is now positioned by the Services trigger wrapper itself.
- Removed the old header-right anchoring (`right-*`) that caused the mega menu to open far to the right.
- Added explicit inline `left: 0`, `right: auto`, and `top: 100%` positioning so Tailwind/CSS cascade cannot move it back to the header edge.
- Reduced desktop mega-menu width to 760px so it remains inside typical laptop viewports when left-aligned under Services.
- Added a dedicated top-left opening animation and a high z-index.
