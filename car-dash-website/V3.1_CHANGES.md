# Car Dash Detailing V3.1

## Twilio SMS is now active

V3.1 uses the approved Twilio Messaging Service through server-only environment variables.

- Staff quote-chat replies send an SMS only when the customer opted in and has not been active in the chat for about 90 seconds.
- Final quotes send the exact quoted price by SMS when the opted-in customer is offline.
- New booking requests send a receipt/total SMS when the booking form SMS checkbox was selected.
- Booking status changes to confirmed, cancelled, or completed send an SMS when that booking has SMS consent.
- SMS failures are logged server-side and never prevent the website action from completing.
- Every SMS includes STOP/HELP instructions.

## Review cleanup

The obsolete owner-managed website review panel and its old custom review API routes were removed. Public Google Reviews and the public Reviews page remain unchanged.

## Database safety

No new Prisma fields or migrations are required for this release. The production build remains `prisma generate && next build` and does not run `prisma db push` automatically.
