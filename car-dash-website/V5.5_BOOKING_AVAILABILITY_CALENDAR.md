# Car Dash Detailing v5.5.0 — Booking Availability & Calendar Controls

## New booking availability controls
- Owner dashboard now has a full Booking Settings panel.
- Set each weekday as available or unavailable.
- Add/remove the exact appointment times offered on each weekday.
- Add specific date overrides for days off, vacations, class days, or special hours.
- A date override can close the whole day or provide a custom set of times.

## Double-booking protection
- Public availability removes times already used by pending or confirmed bookings.
- Booking creation re-checks the slot on the server before saving.
- A PostgreSQL transaction advisory lock protects the selected date/time so two customers submitting at nearly the same moment cannot both take the same active slot.
- Backend validation also confirms that an online-booked time is still part of the owner’s current availability schedule.
- Completed/cancelled bookings no longer block that time.

## Outside/manual bookings
- Owner Bookings now includes “Add outside booking”.
- Add phone, text, in-person, or other off-site bookings directly to Car Dash.
- Manual bookings are confirmed by default and block the same date/time from online booking.
- Manual bookings do not assume SMS consent.

## Editing booked time
- Every owner booking now has Edit date / time.
- Moving an appointment checks for conflicts before saving.
- If the booking has website SMS consent, a schedule-change text is sent automatically.
- Reactivating a cancelled/completed booking is also prevented if another active booking already owns that slot.

## Database
- No Prisma schema migration is required.
- Availability is stored in the existing SiteContent table under `bookingAvailabilityConfig`.
