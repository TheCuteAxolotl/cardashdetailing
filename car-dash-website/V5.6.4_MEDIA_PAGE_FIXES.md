# v5.6.4 — Media Placement Audit + Page Fixes

This update audits the Photos & Videos system after the v5.6 redesign and reconnects every current media placement to a visible public page.

## Fixed placement bugs
- Restored the All Services hero (`services-hero`) so Service Hub / All Services photos actually display.
- Restored hero photos on Car Detailing Packages, Interior Detailing, Exterior Detailing, Paint Correction, Ceramic Coatings, Marine Detailing, and Booking / Contact.
- Restored results media on the three pricing pages and Marine Detailing.
- Restored the Homepage showcase, prices-section media, booking-section media, and story media.
- Restored About values media.
- Added optional media areas for All Services, Reviews, FAQ, Booking / Contact, Exact Quote, and Instant Estimate.
- All optional media sections disappear completely when no media is assigned, so empty media spots do not clutter the public site.

## Package + service proof
- Package-level and included-item media remain tap-to-enlarge.
- Added media placements for every active custom/specialty service (`service-<id>`).
- Individual service media now appears next to that service on the homepage and All Services page.

## Owner media manager
- Centralized static media placement definitions to prevent the dashboard and public pages from drifting apart again.
- Added a “Needs attention” filter for legacy/unmapped media and videos accidentally stored in photo-only hero spots.
- Added direct “Open page” preview links so you can immediately see where each media placement appears.
- Hero placements are now clearly photo-only and the API enforces that rule.
- Existing legacy/custom media stays visible in the dashboard so it can be reassigned instead of disappearing.

## Video links
- YouTube / YouTube Shorts remain supported.
- Vimeo remains supported.
- Added Instagram Reel/post embed support.
- Direct MP4/WebM/etc. links and small uploaded video clips remain supported.

## Reliability
- Media fetches used by public galleries/strips request fresh data after Owner Dashboard changes.
- Static placement audit reports no orphaned current placement.
- Alias-import audit reports no missing local imports.
- 182 TS/TSX files pass TypeScript transpile/syntax diagnostics.
- A full Next.js type/build check still requires installed project dependencies and should be completed by Vercel on deploy.
