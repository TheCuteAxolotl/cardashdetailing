# Car Dash Detailing — Site Customization

The public website is designed to be controlled from the Owner Dashboard.

## Website wording
Open **Owner Dashboard → Website Editor** to change homepage copy, services copy, gallery/review/contact hero copy, About page content, FAQ questions/answers, and footer text.

## Website photos
Open **Owner Dashboard → Gallery** and choose a placement when uploading a photo. Available placements include:
- Homepage main background
- Homepage showcase large / small
- Homepage story
- Homepage services background
- Homepage booking background
- Services background
- Gallery background
- Reviews background
- Contact background
- About background / story / values background
- FAQ background
- Public gallery / before-after / portfolio

## Social links
Facebook, Instagram, and Google buttons are included on the homepage and footer using the supplied Car Dash links.

## Support
The existing support widget, Discord support notifications, live website replies, anti-spam controls, and owner-only block tools are preserved.
