# Car Dash Detailing v5.6.8 — Service-Specific Promo Pricing

This release extends the existing discount-code system with service/package restrictions and exact promotional service pricing.

## New discount controls

Owner → Booking Settings → Discount Codes now supports:

- **Applies to** — choose all services/packages or restrict the code to one exact bookable package/service.
- **Set service price to $** — sets the selected service's base price to an exact promotional price instead of subtracting a generic dollar amount.
- Existing **Percent off** and **Fixed dollars off** modes remain unchanged.
- Existing usage limits, one-use-per-customer rules, expiration dates, active status, and usage tracking remain compatible.

## Example: Essential Exterior Detail for $40

Create or edit a code and choose:

- Discount type: **Set service price to $**
- Promo service price: **40**
- Applies to: **Exterior Only → Essential Exterior Detail**

The code is rejected for every other service/package.

If the customer adds optional add-ons, only the service base price is changed to $40. Add-ons keep their normal prices. For example, a $30 add-on produces a $70 booking total.

## Enforcement

The restriction is checked twice:

1. When the customer presses **Apply** in the booking form.
2. Again on the server when the booking is submitted, using the server-verified selected service/package.

This prevents a customer from applying a service-specific code and then switching to a different service, or bypassing the browser UI.

## Compatibility

No Prisma migration is required. Discount configuration is still stored in the existing `SiteContent` JSON record. Existing discount codes with no service restriction continue to work across all services exactly as before.
