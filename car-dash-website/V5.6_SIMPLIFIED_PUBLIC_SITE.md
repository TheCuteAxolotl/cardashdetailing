# Car Dash Detailing v5.6.0

## Simplified public website redesign

This release changes the public site around one customer path: **see the price, pick a service, and book**.

### Main changes
- Rebuilt the public header with a short navigation: Prices, Gallery, Reviews, FAQ, Help, and Book now.
- Rebuilt the homepage so standard pricing and booking are on the same page.
- Shows Full Detail, Interior Only, and Exterior Only package prices for Coupe, Sedan, and Truck/SUV at the same time.
- Clicking a package price carries the package and vehicle size directly into the booking form.
- Add-ons and active specialty services are shown in the same pricing area.
- Booking is embedded directly on the homepage.
- Simplified the booking form into four sections: Service, Car + Contact, Date + Time, Optional.
- Kept unavailable/full dates disabled and keeps booked times unavailable.
- Simplified Services, Contact, About, FAQ, Gallery, Reviews, Products We Use, Paint Correction, Ceramic Coating, and Marine pages.
- Kept dedicated service pages for search/SEO and deeper information, but they are no longer required for the normal booking flow.
- Simplified the footer and related-service links.
- Reduced oversized hero sections, giant card grids, repeated CTAs, and nested public navigation.
- Preserved the customer account system, owner/staff dashboards, booking availability, manual bookings, discounts, quotes, SMS, phone, warranties, roles, and permissions.

### Deployment
- No new environment variables.
- No Prisma schema migration required by this redesign.
- Existing editable website content and pricing configuration are reused.
