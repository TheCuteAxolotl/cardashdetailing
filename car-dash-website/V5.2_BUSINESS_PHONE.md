# V5.2.0 — Car Dash Business Phone

This release adds incoming voice calls to the same Twilio business number used by Car Dash.

## What it does

- Routes incoming calls through `/api/voice/inbound`.
- Forwards allowed calls to the owner's phone configured in `TWILIO_FORWARD_TO_NUMBER`.
- Uses the Car Dash business number as the forwarded caller ID, so the owner can save that number as a contact and still receive calls when unknown callers are silenced.
- Saves recent call history in the Owner Dashboard under **Business Phone**.
- Matches caller numbers to recent bookings when possible.
- Lets the owner block a number manually or directly from call history.
- Blocked callers are rejected before forwarding using Twilio `<Reject>`.
- Lets the owner unblock numbers at any time.
- Includes a **Repair Voice Connection** button that configures the Twilio phone number's incoming Voice webhook.
- If the forwarded call is busy, unanswered, failed, or canceled, the caller hears a short message asking them to text the same Car Dash number.

## Vercel environment variables

Add these variables to the same Vercel project that already contains your Twilio SMS credentials:

```text
TWILIO_VOICE_NUMBER=+1XXXXXXXXXX
TWILIO_FORWARD_TO_NUMBER=+1XXXXXXXXXX
```

- `TWILIO_VOICE_NUMBER` = the **voice-capable** Twilio Car Dash business phone number customers call.
- `TWILIO_FORWARD_TO_NUMBER` = the personal/mobile phone that should ring when customers call Car Dash.

The existing variables are also required:

```text
TWILIO_ACCOUNT_SID=...
TWILIO_AUTH_TOKEN=...
NEXT_PUBLIC_SITE_URL=https://cardashdetailing.com
```

Optional override:

```text
TWILIO_VOICE_WEBHOOK_URL=https://cardashdetailing.com/api/voice/inbound
```

You normally do not need the override because the app builds this URL from `NEXT_PUBLIC_SITE_URL`.

## After deployment

1. Add `TWILIO_VOICE_NUMBER` and `TWILIO_FORWARD_TO_NUMBER` in Vercel.
2. Redeploy the site so the new environment variables are loaded.
3. Open **Owner Dashboard → Business Phone**.
4. Click **Repair Voice Connection** if the Voice connection is amber.
5. Save the Car Dash Twilio number as **Car Dash Detailing** in the iPhone's contacts.
6. Call the business number from another phone to test forwarding and call history.
7. Use **Block** next to a test call if you want to verify call blocking, then use **Unblock** to restore it.

## Privacy / security notes

- The forward-to number is only exposed to the owner dashboard as the last four digits.
- Voice webhooks validate Twilio signatures before routing calls.
- Blocking controls and call history are owner-only.
- A blocked call is rejected before `<Dial>` is used, so it never reaches the forwarded phone.
