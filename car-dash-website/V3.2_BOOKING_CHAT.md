# Car Dash V3.2 — Booking Chat

V3.2 adds a dedicated conversation to every booking without replacing the existing quote-chat flow.

## What changed

- Owner and admin booking cards now include **Chat with customer**.
- Signed-in customers can open **Message Car Dash** from each booking in Account.
- Guest bookings receive a secure booking-chat URL immediately after submission; if they opted into SMS, the confirmation text also includes that secure link.
- Booking chat polls for new messages and tracks recent customer presence.
- Staff replies send an SMS only when the customer opted in and is not currently/recently active in the booking chat.
- Customer booking-chat replies notify the existing booking Discord webhook.
- Booking status changes are written into the booking conversation as system messages.
- Booking status SMS messages now include the secure conversation link.
- Booking chat works for bookings created directly from fixed-price services and bookings converted from accepted quotes.
- Deleting an eligible booking also deletes its booking conversation through database cascade rules.

## Database safety

V3.2 adds only two new tables: `BookingConversation` and `BookingMessage`. It does not remove or rewrite existing booking, quote, user, or service data.

To avoid putting `prisma db push` back into every Vercel deployment, the booking-chat API creates these additive tables lazily with `CREATE TABLE IF NOT EXISTS` the first time booking chat is used. The normal build remains:

`prisma generate && next build`

## Existing integrations

- Twilio SMS: retained
- Discord booking notifications: retained and extended to customer booking-chat replies
- Quote chats: retained
- Google Reviews: retained
- Owner/admin permissions: retained
