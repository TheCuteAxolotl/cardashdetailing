# Car Dash Detailing v5.6.2

## Photos + videos where customers choose a package

This update adds lightweight visual proof without turning the pricing section into another gallery.

- The Owner Dashboard media manager now supports photos, small direct video uploads, YouTube/Vimeo links, and direct video-file URLs.
- Package cards can have a compact "See this package" media strip. Clicking a thumbnail opens a full-screen lightbox.
- Every package inclusion can have its own photo/video placement. If media exists, the included item becomes a subtle tappable row. Example: tapping "Foam + hand wash" can open a hand-washing clip.
- The package proof UI is hidden when no media has been assigned, so pricing cards stay clean.
- Public gallery and pricing media strips now support video and click-to-enlarge behavior.
- Package-level media can be labeled Before / After / Finished / Process so customers can quickly understand the result.
- Hero/background image slots remain photo-first; video records are ignored by image-only hero renderers.

## Video storage note

The current site stores image records in the existing GalleryImage table, so no database migration is required. Tiny video clips up to 2.5 MB can be uploaded directly. Normal phone videos should use a YouTube (including unlisted), Vimeo, or direct .mp4/.webm video URL to avoid oversized serverless requests and database bloat.
