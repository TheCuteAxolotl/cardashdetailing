# Car Dash Detailing v5.6.1

Booking submission hotfix.

- Fixes Prisma failing to deserialize PostgreSQL `void` from `pg_advisory_xact_lock`.
- Keeps the transaction advisory lock used to prevent two customers from taking the same active appointment slot.
- Casts the lock result to PostgreSQL `text`, which Prisma can deserialize safely.
- No database migration or new environment variables are required.
