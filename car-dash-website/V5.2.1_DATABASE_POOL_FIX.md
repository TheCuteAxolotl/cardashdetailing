# v5.2.1 — Prisma pooled runtime connection fix

This build adds support for a user-managed `POOLED_DATABASE_URL` environment variable.

## Why
The Vercel Prisma Marketplace integration may expose managed `DATABASE_URL` / `PRISMA_DATABASE_URL` values using the direct `db.prisma.io` hostname. Direct TCP connections have a much lower connection ceiling and can fail in serverless environments with `Too many database connections opened`.

## Vercel setup
1. Copy the existing direct Prisma URL privately.
2. Add a new Vercel environment variable named `POOLED_DATABASE_URL`.
3. Use the same URL, changing only the hostname from `db.prisma.io` to `pooled.db.prisma.io`.
4. Keep the existing managed Prisma variables unchanged.
5. Redeploy.

At runtime this build prefers any pooled URL it finds, including `POOLED_DATABASE_URL`. Prisma CLI commands can continue using the integration-managed direct `DATABASE_URL`.
